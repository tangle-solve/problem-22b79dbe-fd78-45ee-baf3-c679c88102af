### ALGO-000197: Polynomial-time Learning Parity with Noise
- **Subfield:** Learning complexity and cryptographic foundations
- **Open:** Recover an unknown binary parity from polynomially many randomly sampled examples corrupted by a fixed noise rate below one half, in polynomial time.
- **Status:** Subexponential algorithms are known; general polynomial-time learning remains open and is widely used as a hardness assumption.
- **Type:** theory
- **Why:** A minimal noisy learning problem with major cryptographic consequences.
- **Key works:** Blum, Kalai, and Wasserman (2003), *Noise-Tolerant Learning, the Parity Problem, and the Statistical Query Model*.
- **Related:** Coding theory—decoding random linear codes; cryptography—LPN-based primitives.
